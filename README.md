# Oracle-Package-Example
This code is to show an example of knowledge using packages, procedures, and functions in Oracle. This was ran in Onecompiler.org

# Database Setup
This sets up the tables that are going to be utilized for the example

# PL/SQL Package
This is the implementation of a package called "employee_package". 
## It has two procedures 
* give_employee_raise
* change_employee_department

## And two functions 
* get_salary
* get_employee_name
